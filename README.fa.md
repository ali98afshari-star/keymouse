# KeyMouse — موس با کیبورد، برای Linux Mint / XFCE

یه دکمه رو نگه دار، با کلیدهای جهت‌دار موس رو حرکت بده. همین.

> نسخه‌ی انگلیسی: [README.md](README.md)

## نصب — یک خط

فایل deb را از صفحه‌ی [Releases](https://github.com/ali98afshari-star/keymouse/releases) بگیر و نصب کن:

```bash
sudo dpkg -i keymouse_2.0.0_amd64.deb
sudo apt install -f   # اگر وابستگی خواست
```

بعد لاگ‌اوت / لاگین کن، یا در ترمینال بزن `keymouse`.

نصب دستی از روی tar.gz هم هست: بازش کن و `./install.sh` را بزن (بدون روت؛
فقط دو فایل باینری را در `~/.local/bin` می‌گذارد).

یا از روی سورس بساز:

```bash
git clone https://github.com/ali98afshari-star/keymouse.git && cd keymouse
cargo build --release && ./install.sh
```

**به‌روزرسانی از نسخه‌ی ۱ (پایتون):** قبل از نصب نسخه‌ی ۲، دیمون قدیمی
پایتون را متوقف کن (`pkill -f keymouse.py`) — `install.sh` خودش این کار
را می‌کند. کانفیگ قدیمی (`~/.config/keymouse/config.ini`) به‌صورت
خودکار به فرمت جدید (`config.toml`) تبدیل می‌شود.

## استفاده

| نگه دار + بزن | چه می‌شود |
|---|---|
| **Ctrl راست** (نگه‌دار) + `↑ ↓ ← →` | حرکت موس (مورب هم کار می‌کند) |
| + `Shift` | سریع ×۳ |
| + `Alt` | آهسته و دقیق |
| `Enter` (در حالی که Ctrl راست نگه داشته‌ای) | کلیک چپ — نگه‌اش دار = درگ |
| `.` | کلیک راست |
| `/` | کلیک وسط |
| `PageUp` / `PageDown` | اسکرول بالا / پایین (با نگه داشتن تکرار می‌شود) |
| `Esc` | رها کردن همه‌چیز |

سرعت اول آهسته شروع می‌شود و هرچه جهت را بیشتر نگه داری تندتر می‌شود،
برای همین هم نشانه‌گیری دقیق راحت است و هم رد کردن صفحه سریع.

نکته: تا وقتی Ctrl راست را نگه داشته‌ای، کلیدهای جهت‌دار به برنامه‌ی
زیرین نمی‌رسند (یعنی Ctrl+Arrow یا Ctrl+Enter داخل برنامه اتفاق نمی‌افتد).
به محض رها کردن Ctrl راست، کیبورد دقیقاً مثل قبل کار می‌کند. Ctrl چپ
اصلاً دست نخورده و همیشه مثل همیشه است.

## تنظیمات — پنجره‌ی مدرن (تیره)

```bash
keymouse-settings
```

یا از منوی برنامه‌ها: **KeyMouse Settings**. در آنجا می‌توانی:

- **هر کلیدی را مثل بازی‌ها عوض کنی:** روی ردیف کلیک کن، بعد کلید
  جدید را بزن — همان کلید ثبت می‌شود (Esc لغو می‌کند). این برای همه‌ی
  کلیدها کار می‌کند: دکمه‌ی نگه‌دارنده، چهار جهت، سریع، آهسته، سه کلیک،
  دو اسکرول و لغو.
- **دکمه‌ی نگه‌دارنده** را عوض کنی (Ctrl راست/چپ، Caps Lock، Alt راست، Super)
- **کلیک چپ/راست/وسط** را به کلید دیگری بدهی
- **سرعت معمولی** (فقط Ctrl)، **سرعت سریع** (Ctrl+Shift) و **سرعت دقیق**
  (Ctrl+Alt) را با اسلایدر تنظیم کنی — حداکثر سرعت هر سه حالت همان‌جا
  به پیکسل بر ثانیه نشان داده می‌شود
- دیمون را شروع/متوقف کنی و استارت خودکار با ورود را روشن/خاموش کنی

دکمه‌ی «Apply & Restart» تنظیمات را می‌نویسد در
`~/.config/keymouse/config.toml` و دیمون را ری‌استارت می‌کند.

## نسخه‌ی ۲ — بازنویسی کامل با Rust

- **خیلی سبک‌تر:** دیمون یک باینری ۸۶۱ کیلوبایتی است، بدون پایتون،
  بدون venv، بدون `python-xlib`. حافظه‌ی مصرفی حدود **۲٫۶ مگابایت**
  است (نسخه‌ی پایتون ~۱۶٫۶ مگابایت بود — حدود ۶ برابر سبک‌تر).
  استارت آنی است.
- **همه‌ی تنظیمات** در پنجره‌ی تنظیمات و در فایل کانفیگ (`config.toml`)
  قابل تغییرند: همه‌ی کلیدها، سرعت‌ها، شتاب، tick، تکرار اسکرول.
- **پنجره‌ی تنظیمات جدید** با egui، تم تیره، بخش‌های مشخص
  (Status / Keybindings / Pointer speed / Behaviour) و پیش‌نمایش زنده‌ی
  سرعت.
- رفتار دقیقاً مثل نسخه‌ی ۱٫۱ است (همان کلیدها، همان شتاب، همان
  ضدتکرار کلیک، همان امنیت درگ، همان اسکرول، همان Esc، همان قفل
  تک‌نسخه‌ای).

نسخه‌ی پایتون (۱٫۲، با پنجره‌ی تنظیمات تیره و یک کلید جداگانه برای
درگ) هنوز در پوشه‌ی `python-v1/` هست و کار می‌کند.

## چرا این را ساختم، با اینکه برنامه‌های آماده هست؟

- **MouseKeys داخلی X11** از قبل هست (`setxkbmap -option keypad:pointerkeys`
  بعد Shift+NumLock)، ولی فقط با **نام‌پد** کار می‌کند، نه کلیدهای جهت‌دار،
  و اگر لپ‌تاپت نام‌پد ندارد عملاً بی‌فایده است.
- **warpd** مودال است (با Alt+Meta+C وارد مود می‌شوی، بعد hjkl) و
  سه سال است آپدیت نشده؛ روی XFCE هم گزارش هنگ دارد.
- **keynav** صفحه را نصف‌نصف می‌کند تا به نقطه برسی، حرکت پیوسته نیست.
- هیچ‌کدام دقیقاً «یه دکمه رو نگه دار + جهت‌ها» نبودند، پس این برنامه
  ساخته شد.

## تست

```bash
keymouse --test        # تست منطق سرعت/جهت/کانفیگ، بدون نیاز به X
cargo test --release   # همه‌ی تست‌ها: ۱۲ تست واحد + تست e2e زیر Xvfb
                       # (حرکت واقعی پوینتر، کلیک، اسکرول) + تست دود
                       # پنجره‌ی تنظیمات
```

## حذف

```bash
./uninstall.sh        # در نسخه‌ی tar.gz / سورس
# یا برای deb:
sudo dpkg -r keymouse
```

## محدودیت‌ها

- فقط **X11**. مینت XFCE به‌طور پیش‌فرض X11 است، پس مشکلی نیست؛
  روی Wayland کار نمی‌کند.
- اگر برنامه‌ی دیگری همزمان کیبورد را grab کرده باشد، keymouse
  نمی‌تواند دکمه را بگیرد و در لاگ می‌نویسد.
